プライバシーポリシー

アプリ名：筋PFCログ（以下「本アプリ」）
運営：SciPhysique
制定日：2026年6月29日
最終改定日：2026年10月7日

SciPhysique（以下「当方」）は、本アプリにおけるユーザーの情報の取り扱いについて、以下のとおりプライバシーポリシー（以下「本ポリシー」）を定めます。

1. 取得する情報

本アプリでは、以下の情報を取り扱います。

  • ユーザーが入力する記録データ：食事のPFC（たんぱく質・脂質・炭水化物）、カロリー、体重、体脂肪率、トレーニングの記録、各種設定値など。原本はお使いの端末内（SwiftData）に保存されます。友達機能を利用する場合に限り、下記の「友達・グループ共有データ」を当方が利用するFirebaseへ送信します。
  • 進捗写真：ユーザーが履歴カレンダーから明示的に選択した写真を、位置情報等のメタデータを除去してアプリ専用の端末内領域へ保存します。Firebase、友達・グループ共有、広告配信、CSV、通常のAI分析用テキストには含めません。「写真付きでAIへ共有」を実行した場合に限り、選択期間内の写真から端末内で作成した比較画像を、iOSの標準共有機能を通じてユーザーが選んだ共有先へ渡します。
  • 友達アカウント情報：Appleアカウントによる認証識別子、ユーザーが設定するニックネーム・公開ID、友達申請、友達関係、グループ参加、ブロックおよび通報に必要な情報。
  • 友達・グループ共有データ：承認した友達または参加グループがある場合、共有設定で選んだ部位・運動時間・消費カロリー・週間目標と進捗・PFC・食事内容を共有します。種目の詳細を明示的にオンにすると、種目名、方式、重量、回数、セット内訳、アシストなども共有します。「この日の自由メモ」は初期状態でオフとし、共有設定で明示的にオンにした場合だけ最大200文字を共有します。消費カロリーは手入力した記録値を優先し、なければ共通60kg基準の推定値を使用します。共有項目は個別にオフにでき、オフにした内容は閲覧可能な過去の共有文書からも削除します。体重、体脂肪率、睡眠、疲労感、飲酒、外食、種目ごとの自由記述メモ、次回へのメモおよびHealthKit由来の値は友達機能へ送信・共有しません。
  • 広告配信に伴い自動的に取得される情報：本アプリは広告配信のため Google AdMob を利用しています。AdMob およびその提携先により、広告識別子（IDFA）、端末情報、アプリの利用状況、おおよその位置情報、Cookie や類似技術による情報が取得される場合があります。
  • 購入に関する情報：将来的に有料のサブスクリプション等を提供する場合、その決済は Apple（App Store）を通じて処理されます。クレジットカード番号等の決済情報を当方が取得・保存することはありません。
  • ヘルスケア（HealthKit）から読み取る情報：ユーザーが「ヘルスケア連携」を有効にした場合に限り、Appleの「ヘルスケア」に保存された体重・体脂肪率・睡眠・食事（カロリー・たんぱく質・脂質・炭水化物）・ワークアウト（種別・時間・距離・消費エネルギー）・心拍数・安静時心拍数・VO₂maxを読み取り、本アプリ内の記録または運動傾向の分析に使用します。「今すぐ取り込む」を実行した場合、日次に集計したワークアウト時間と有酸素の距離・消費カロリー・平均ペース・平均心拍数は端末内の記録へ保存します。分析グラフ用のワークアウト別データ、日中・安静時心拍数、VO₂maxはアプリのデータベースへ複製せず、分析表示時に端末内で集計します。読み取ったデータは当方のサーバーやiCloudへ送信されません。これらの健康データを広告配信・マーケティングに利用したり、当方が自動的に第三者へ提供することはありません。連携はユーザーが任意で有効化するもので、アプリ内の項目設定またはヘルスケアの許可設定からいつでも無効化できます。

2. 利用目的

  • 本アプリの機能（記録・履歴・分析・CSV出力等）の提供のため
  • ユーザーが明示的に選択したAI分析用テキスト・CSV・進捗写真比較画像の書き出しのため
  • 広告の表示および最適化のため
  • サブスクリプション等の購入状態の確認および機能提供のため
  • 本アプリの品質向上および不具合の解析のため
  • 友達申請、グループ、記録共有、ブロック、通報および不正利用防止のため

3. 第三者への提供・外部サービスの利用

本アプリは以下の外部サービスを利用しており、これらのサービスによる情報の取得・利用は各社のポリシーに従います。

  • Google AdMob（広告配信）： Googleプライバシーポリシー / 広告における情報の使用について
  • Apple（App内課金の決済処理）： Appleプライバシーポリシー
  • Apple（Sign in with Appleによる友達アカウント認証）： Appleプライバシーポリシー
  • Google Firebase Authentication / Cloud Firestore / App Check（認証、友達関係・共有データの保存、不正アクセス対策）： Firebaseのプライバシーとセキュリティ

これらの広告配信事業者は、ユーザーの興味に応じた広告を表示するために、当該情報を米国を含む国外のサーバーで処理する場合があります。

Firebase上のデータは、サービス提供のため米国を含む日本国外で処理される場合があります。当方は、利用目的の限定、アクセス制御、通信の暗号化およびApp Check等により安全管理を行います。

当方は、利用する第三者サービスについて、本ポリシーおよび適用法令が求める水準と同等以上の保護措置を講じる事業者を選定し、各サービスの契約条件・安全管理措置・プライバシー情報を確認します。

ユーザーによる書き出し：本アプリでCSV、AI分析用テキスト、または進捗写真比較画像の共有操作を行った場合、ユーザーが選択した内容がiOSの標準共有機能を通じて、ユーザーが指定したアプリまたは相手へ渡されます。進捗写真比較画像は共有前に外部送信の確認を表示します。当方が送信先を選択したり、書き出した内容を取得・保存したりすることはありません。共有後の取り扱いは、送信先サービスおよび受信者の管理となります。トレーニング・PFC・月次レポートの画像共有機能は提供していません。

3.1 利用者情報の外部送信

本アプリに組み込まれた外部サービスにより、次の情報が端末外へ送信されます。当方における利用目的と送信先における利用目的は次のとおりです。

  • Google LLC（Google AdMob）：広告識別子、端末・OS・アプリに関する情報、広告の表示・操作情報、IPアドレス等から得られるおおよその地域、診断・パフォーマンス情報が送信される場合があります。当方は広告表示、広告効果の把握、不正防止のために利用し、Google LLCは広告配信、測定、分析、不正防止等のために取り扱います。ATTを許可しない場合はIDFAを使ったトラッキングを行わず、端末の設定から許可を変更できます。詳細はGoogleの電気通信事業法に基づく表示をご確認ください。
  • Google LLC（Firebase Authentication / Cloud Firestore / App Check）：Apple認証識別子、Firebase利用者ID、ニックネーム・公開ID、友達・グループ関係、許可対象の共有データ、端末・アプリの真正性確認情報、通信・エラーに関する情報が送信されます。当方はログイン、友達・グループ共有、アクセス制御、不正利用防止、障害対応のために利用し、Google LLCはFirebaseサービスの提供、保護、維持、改善のために取り扱います。友達機能へサインインしない場合、プロフィール・友達関係・共有データはFirebaseへ送信しません。

4. 友達・グループ共有と安全機能

友達申請の承認またはグループ参加の前に、共有対象をアプリ内で案内します。関係成立後は許可された共有項目を自動共有します。過去の記録を新しい相手へ遡って公開しません。友達削除またはグループ退出後はその関係による閲覧を停止し、ブロックした相手とは友達・グループの双方で相互表示を停止します。不適切な内容や利用者はアプリ内から通報できます。

5. トラッキングと広告のパーソナライズについて

本アプリは、iOS の App Tracking Transparency（ATT）の仕組みに従い、トラッキングの許可をユーザーに確認します。ユーザーは端末の「設定 > プライバシーとセキュリティ > トラッキング」からいつでも許可を変更でき、許可しない場合でも本アプリの基本機能はご利用いただけます（表示される広告がパーソナライズされなくなる場合があります）。

6. データの保存と削除

ユーザーが入力した記録データとHealthKitから取り込んだ記録データの原本は端末内に保存されます。進捗写真はアプリ専用の端末内領域へ保存し、iCloudおよび端末バックアップの対象外とします。日次に集計したワークアウト時間と有酸素詳細は本アプリの記録へ保存しますが、分析グラフ用のワークアウト別データ、日中・安静時心拍数、VO₂maxは表示時に端末内で一時的に読み取り・集計し、本アプリのデータベースには保存しません。本アプリはこれらをCloudKitまたはiCloudへ保存しません。本アプリを端末から削除すると、本アプリ内に保存されたデータと進捗写真も削除されます。

友達・グループの共有記録、プロフィールおよび関係情報は、友達機能の提供に必要な期間Firebaseへ保存します。友達削除・グループ退出・ブロック後はその関係による共有記録の閲覧を停止します。友達アカウントはアプリ内の「友達を管理 > アカウント」からAppleで再認証して削除でき、プロフィール、関係情報および共有データを削除します。所有するグループを削除した場合は、そのグループのメンバー情報と共有データも削除します。端末内の記録は別に管理されるため、友達アカウント削除では消えません。法令遵守・不正利用対応に必要な通報記録、削除受付記録等は、必要な範囲で一定期間保存する場合があります。

ユーザーが書き出したテキスト・CSV・進捗写真比較画像等は共有先に残る場合があります。広告関連の情報の保持期間については、各外部サービスのポリシーをご参照ください。
